# Estilos CSL

- `aasjournal.csl`: "The Astrophysical Journal" (autor-año), del repositorio oficial de estilos CSL
  (https://github.com/citation-style-language/styles). Se usa con `cite-style: "author-year"`.
- `numeric.csl`: "IEEE" (numérico), del mismo repositorio. Se usa con `cite-style: "numeric"`.

Ambos tienen licencia CC BY-SA 3.0 (ver el encabezado `<rights>` de cada archivo).
